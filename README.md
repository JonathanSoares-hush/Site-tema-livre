# Site tema livre

-Atividade realizada para praticar os comandos de HTML com qualquer tema.

## Tecnologia

HTML.

## Como executar

-Abra o arquivo index.html em qualquer navegador.

## Autoria 

Elaborada por Jonathan Felipe Soares.

## Descrição

-O site funciona como qualquer outro site, com links e etc. Falando e ensinando um pouco sobre o jogo "Stardew Valley"

  ## Estrutura das Páginas
- `index.html`: **Início** — Apresentação geral do tema Stardew Valley, rotina da fazenda, listas estruturadas e convite ao cadastro.
- `sobre.html`: **Sobre** — Sumário com âncoras internas, artigos detalhados da história e vila, nota lateral de curiosidades, glossário em lista de definição e links externos.
- `dados.html`: **Dados** — Tabela estatística completa com colunas de cultivo, estações, datas (`<time>`), tempos de crescimento e preços de venda com rodapé formatado.
- `cadastro.html`: **Cadastro** — Formulário completo com 3 fieldsets agrupando campos com validações nativas do HTML5 (tipos específicos, min/max, step, select, radio, checkbox e textarea limitado).
- `contato.html`: **Contato** — Endereço formal da prefeitura (`<address>`), horários em `<dl>`, link externo para mapa e formulário de envio de mensagem.
